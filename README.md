# WeatherApp
WeatherApp est une application mobile développée en Java pour afficher les prévisions météorologiques d'une ville à l'aide de l'API OpenWeather. 
Application permet à l'utilisateur de consulter les conditions climatiques actuelles ainsi que les prévisions à court terme pour une ville donnée.

## Fonctionnalités

- Affichage des prévisions météorologiques actuelles pour une ville donnée.
- Présentation des températures, conditions climatiques (pluie, ensoleillé, etc.) et d'autres détails météorologiques.
- Utilisation de l'API OpenWeather pour récupérer les données en temps réel et les prévesions du 7 jours.

## Prérequis
Avant de commencer, assurez-vous que vous avez installé les éléments suivants :

- **Java JDK 8 ou supérieur**
- **Android Studio** (pour les applications Android)
- **API Key** d'OpenWeather (disponible [ici](https://openweathermap.org/api)).
